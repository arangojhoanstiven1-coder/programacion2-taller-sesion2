# programacion2-taller-sesion2
Decisiones de modelado: Se decidió trabajar con las clases Vehiculo y Celda porque representan las entidades principales del sistema. Los atributos se definieron como privados para proteger la información y acceder a ella mediante métodos públicos. Vehiculo almacena la placa, el tipo y el propietario, mientras que Celda guarda su código, su estado de ocupación y el vehículo asignado. La celda se crea inicialmente libre y los métodos ocupar() y liberar() validan que las operaciones sean posibles antes de modificar su estado. Además, cada celda puede tener como máximo un vehículo, evitando que una misma celda sea ocupada por varios vehículos al mismo tiempo.
